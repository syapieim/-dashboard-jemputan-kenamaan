# Dashboard Jemputan Kenamaan 2026

Dashboard interaktif analisis permohonan undangan orang kenamaan dan ahli politik bagi Jabatan Pendidikan Negeri Sabah.

## Kandungan
- KPI keseluruhan permohonan
- Analisis mengikut PPD
- Trend bulanan Januari–Ogos 2026
- Pecahan ADUN, Ahli Parlimen, Ahli Parlimen & ADUN, dan Lain-lain
- Analisis tujuan jemputan
- Penapis PPD, bulan dan kategori
- Jadual ranking PPD dan dapatan utama

## Aktifkan GitHub Pages
1. Buka **Settings** repository.
2. Pilih **Pages**.
3. Di bahagian **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**.
5. Klik **Save**.

Selepas aktif, dashboard akan tersedia melalui GitHub Pages repository ini.
